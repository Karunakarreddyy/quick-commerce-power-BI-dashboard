# Quick-Commerce Analytics Dashboard | Power BI

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze the performance of a quick-commerce business across sales, customers, products, delivery operations, customer satisfaction, and payment methods.

The project focuses on transforming raw transactional data into meaningful business insights through data cleaning, data modeling, DAX calculations, and interactive visualization.

## 🎯 Business Objectives

The dashboard was developed to answer key business questions:

- How much revenue is being generated?
- How many orders and customers does the business have?
- Which products and categories generate the most revenue?
- Which cities have stronger customer and operational performance?
- How effective is the delivery operation?
- How satisfied are customers?
- Which payment methods contribute most to revenue?

## 🧹 Data Cleaning & Preparation

Data preparation was performed using Power Query.

Key activities included:

- Removed duplicate records
- Identified and handled missing values
- Standardized data types
- Cleaned text fields using Trim and Clean
- Validated numeric fields
- Checked rating and delivery data
- Prepared tables for relational modeling

## 🔗 Data Model

The dashboard uses a relational data model connecting:

- Customers → Orders
- Orders → Transactions
- Products → Transactions
- Orders → Ratings
- Orders → Delivery

The model was designed to support accurate filtering and cross-table analysis.
